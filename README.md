# 🗂️ CLASSIFIED ARCHIVE

> A research and information compiling tool documenting conspiracy theories, cryptids, and paranormal phenomena with cited sources and all perspectives.

## Features

- **Archive of theories** — Conspiracy theories, cryptids, paranormal events, government operations, and historical controversies
- **Dual-perspective coverage** — Each file includes both mainstream/official accounts and confidential intelligence briefings
- **Balanced arguments** — Every theory includes fully-sourced arguments both supporting and challenging its existence
- **Cited sources** — Books, government documents, academic papers, documentaries, and witness accounts
- **Classification system** — Files rated UNCLASSIFIED / CONFIDENTIAL / SECRET / TOP SECRET
- **Search & Filter** — Filter by category, search by keyword
- **Top-secret UI** — Dark terminal aesthetic with CRT scanline effect
